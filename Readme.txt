操作方法：
----------------------------------------------------------
・→←↑↓キーで＜移動方向＞
・Aキーで＜次のシーン＞


----------------------------------------------------------
PRポイント：
----------------------------------------------------------
・リザルト画面に点数によって声でリンゴ数を言うことができます。（19個まで、20から＜たくさん＞で言う）
・メインゲームとリザルト画面の点数は図で表示されます。
・mciとPlaysoundAを利用して、BGMとSEが同時に放送できます。
・キャラクターは移動のアニメーションがあります。
